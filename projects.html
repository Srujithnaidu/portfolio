1. Eye Controlled Mouse

An AI-powered computer vision application developed using Python that enables users to control the mouse cursor through eye movements. The system utilizes MediaPipe Face Mesh for real-time eye landmark detection, OpenCV for webcam processing, and PyAutoGUI for mouse automation, providing a hands-free and accessible human-computer interaction experience.

Features

  • Real-time eye tracking using MediaPipe Face Mesh.
  • Cursor movement controlled by eye gaze.
  • Hands-free interaction using a webcam.

Technologies Used

Python, OpenCV, MediaPipe Face Mesh, PyAutoGUI, Keyboard, Time, Collections (Deque)

Challenges

Accurate eye tracking under different lighting conditions, reducing cursor jitter through smoothing, and implementing reliable blink detection for mouse actions.

2. AI Based Voice Assistant

A desktop-based AI voice assistant developed using Python that understands voice commands and automates everyday computer tasks. It combines AI-powered speech recognition with Python automation to provide a hands-free user experience.

Features

  • AI-powered voice command recognition.
  • Opens websites and applications.
  • Takes screenshots and checks internet speed.
  • Performs system operations like shutdown and restart.

Technologies Used

Python, SpeechRecognition, Google Speech API, pyttsx3, PyAutoGUI, Wikipedia API, Webbrowser, Speedtest, OS Module
